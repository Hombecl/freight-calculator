Application to this tool (our design decisions, not claims of measured conversion gains):
- Put Compare A/B in the normal viewer toolbar; do not require users to discover Expand first.
- Let aligned thumbnails and the same three metrics explain alternatives. One recommendation/tradeoff line instead of several repetitive paragraphs and algorithm names.
- Keep the existing palette and slow orbit behavior.
- Preserve usable output: static placement preview if WebGL fails; explicit draft choice when weights are unknown, with no invented zero weights in exports.
- Ask one optional follow-up only after a user requests a different arrangement or missing constraint. Use fixed categories, not cargo details.
